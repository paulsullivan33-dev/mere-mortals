# Privacy

This site is a static collection of guides. It has no accounts, no
comments, and no analytics of my own; I do not collect, receive, or
store any personal data from visitors. (The site is hosted on GitHub
Pages, and GitHub's own policies cover anything their infrastructure
does on its own.)

## The "rclone" application

One personal application is associated with this site for Google
sign-in purposes:

- **What it is:** an OAuth client named **rclone**, used with the
  open-source rclone file-copy tool.
- **Who uses it:** only me, the site's owner, on my own computers.
- **What it does:** it copies my own log files from my own home
  computers to my own Google Drive, so I can read them while away
  from home.
- **What data it touches:** only files in my own Google Drive, under
  my own authorization. It accesses no other person's data, ever.
- **Sharing:** none. Nothing is sold, shared, or sent to any third
  party. The files move between my machines and my own Drive.
- **Revoking access:** I can revoke the app's access at any time from
  my Google Account's third-party access page, which immediately
  ends its ability to reach the Drive.
